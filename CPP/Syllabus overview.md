    2. Array and Linked List
    3. Stack
    4. Queue
    5. Tree and graph ;

Data Structures has 2 types : Primatives and Non Primatives

Prmitive : Int, Float, Char, double etc
Non Primitive : Linear and Non Linear;

Liner: Array, Stack , Queue , Linked List
Non Liner :  Tree, Graphs

Operations in Array : Insertion, Updation, Deletion, Sorting --> Selection sort, bubble sort, Insertion sort, Mereger Sort, Quick sort, Heap sort, Radix Sort, Search --> Binary search linear search;

Operation in Stack: Push, pop
Operation in Queue: Insertion, Deletion
Operation in Linked list: Insertion --> Start, End, Somewhere; Deletion --> Start, End, Somewhere; 

Types of Linked List: Singly LL,Doubly LL, Cyclic LL;

Operations on Tree :  Insertion, Deletion, Traversal--> Preorder, Inorder, Postorder
Operations on Graph :  Insertion, Deletion, Spanning --> Depth First and breadth first, Prims, Krishals
